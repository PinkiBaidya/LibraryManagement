# 📚 UniLibrary – Library Management System

A **Windows Forms Library Management System** developed in **C# and .NET** to manage books, students, and librarians efficiently.

This application helps librarians manage the issuing and returning of books while maintaining organized records of students and library resources.

## 🚀 Features

✔ Manage Students
✔ Manage Books
✔ Issue Books to Students
✔ Return Books
✔ Manage Librarians
✔ Simple and user-friendly dashboard

---

## 🧩 Modules

### 👨‍🎓 Students

* Add new students
* Update student information
* View student list

### 📖 Books

* Add books to the library
* Update book information
* View available books

### 📤 Issue Books

* Issue books to students
* Track issued books

### 📥 Return Books

* Return issued books
* Update book availability

### 👩‍💼 Librarians

* Manage librarian records
